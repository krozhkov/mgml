# HTML Comparison (MJML vs MGML)

This script automates the process of comparing the HTML output generated by the original `mjml` (JavaScript) and the `mgml` port (Golang). 

To prevent false positives caused by formatting differences (such as spaces and line breaks), the generated code is first passed through a minifier. After that, files are compared.

## Prerequisites

Before using the script, you need to install the following external dependencies.

1. **Minify:** A utility for normalizing the generated HTML.
   ```bash
   brew install minify
   ```
2. **Original MJML** You must install the exact version that the parser's behavior is currently synchronized with (currently `4.18.0`).
   ```bash
   npm install -g mjml@4.18.0
   ```

## Usage

**Important:** All commands must be executed from inside the `tests` directory.

* **MJML templates** To run tests against the official templates from the [mjmlio](https://github.com/mjmlio/email-templates) repository:
   ```bash
   ./compare.sh mjmlio-templates/templates
   ```
* **MRML templates** To verify the behavior against the test files from the alternative [mrml](https://github.com/jdrouet/mrml) project:
   ```bash
   ./compare.sh mrml-templates
   ```

## Known Template Issues

Please note that some of the original templates contain syntax errors or trigger known quirks in the original MJML parser. These may cause expected discrepancies during comparison:

* **`street-expo.mjml`:** Incorrect font usage detection. The template only uses the "Inter Tight" font, but the original MJML incorrectly detects the "Inter" font as well because it performs a simple substring match.
* **`ugg-royale.mjml`:** Contains malformed inline CSS. Semicolons are incorrectly used between blocks within the style text.
* **`welcome-email.mjml`:** Contains a malformed `font-family` attribute value. Different font families are missing comma separators (e.g., `font-family="open Sans Helvetica, Arial, sans-serif"`).
